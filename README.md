# Guardrail Blocker

A classic-arcade browser game. A model spits out agents; you run the blocker.

**Play it:** https://nathanslavik-arcade.github.io/guardrail-blocker/

- **Green agents** — let them through. +15 when one reaches your business systems.
- **Red agents** — block them. +10 each; one that gets through costs a life.
- Blocking a green agent costs 25 points.
- Catch the falling Arcade logo for 5 seconds of auto-governance: reds are
  blocked at the shield line, greens are routed straight through.

Agents fall faster and more often the more you handle correctly. Three lives.

Arrow keys or A/D to move, mouse and touch also work, P to pause. Tap the field (or press Esc) to quit back to The Arcade Arcade.

Single self-contained HTML file — no dependencies, no build step. Open
`index.html` directly and it plays offline.
